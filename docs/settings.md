# 设置

默认都打开。

- `mute_enhancements_enabled`：总开关。
- `mute_enhancements_search_muted_tags`：[搜索](search.md)里隐藏免打扰的标签。另外需要打开核心的 `tagging_enabled`。
- `mute_enhancements_search_muted_categories`：搜索里隐藏免打扰的类别。
- `mute_enhancements_search_muted_topics`：搜索里隐藏免打扰的话题。
- `mute_enhancements_search_ignored_users`：搜索里隐藏忽略的用户。
- `mute_enhancements_search_muted_users`：搜索里隐藏免打扰的用户。
- `mute_enhancements_hide_invisible_group_users`：[`group_users`](hidden-group-users.md) 只列出看得到的群组。
- `mute_enhancements_group_mutes`：允许用户[免打扰、忽略群组](group-mutes.md)。
- `mute_enhancements_group_default_users`：允许管理员设置[群组默认屏蔽的用户和群组](group-defaults.md)（群组还需要打开 `mute_enhancements_group_mutes`）。
- `mute_enhancements_group_hide_preferences`：允许管理员[对群组成员隐藏个人设置的“通知”“跟踪”“用户”页面](hide-preferences.md)（每个群组仍默认不隐藏）。
- `mute_enhancements_group_muted_topics`：允许管理员[给群组成员屏蔽话题](group-muted-topics.md)。关闭后，已经设好的免打扰保留，新成员加入时不再设置。
- `mute_enhancements_group_enhanced_ignore`：允许管理员[给群组成员打开 enhanced-ignore 的增强屏蔽选项](group-enhanced-ignore.md)，需要 enhanced-ignore。关闭后，已经打开的选项保留，新成员加入时不再打开。
