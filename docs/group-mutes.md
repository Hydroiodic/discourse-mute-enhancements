# 免打扰和忽略群组

个人设置 → 用户 页面多了“忽略的群组”和“免打扰的群组”两项。选中一个群组，就相当于把它的每个成员都单独设为忽略或免打扰：插件直接写核心的 `ignored_users`/`muted_users` 记录，所以核心对忽略、免打扰用户的所有处理（通知、私信、聊天、话题页隐藏帖子）以及插件的[搜索过滤](search.md)都自动生效。

- 只能选能看到成员的群组（`visible_groups` 和 `members_visible_groups`），不能选自动群组（信任等级、工作人员、所有人）。管理员设置的[默认屏蔽的群组](group-defaults.md#默认屏蔽的群组)可以是隐藏的群组，这时成员的列表里会出现自己选不到的群组。
- 管理员和版主不会被忽略或免打扰，和核心一致；自己也不会。
- 以后加入群组的成员自动生效，退出群组、成为管理人员的成员自动取消。成员变化时立即更新；另有每天一次的任务（`Jobs::MuteEnhancementsReconcileGroupMutes`）兜底，例如处理成员被提升为版主的情况。
- 忽略的有效期是“永久”（和核心忽略对话框里的“永久”一样是 1000 年后），直到取消群组。这些记录不计入核心通知版主“某用户被很多人忽略”的统计（`Jobs::IgnoredUsersSummary`）。
- 一个群组只能是忽略或免打扰之一。和核心一样，已经忽略的人不会再额外设为免打扰。

插件另外记下哪些记录是群组带来的（见[数据存在哪里](data-storage.md)）：

- 用户之前自己设置过的免打扰、忽略不受影响，取消群组时也不会被删掉。
- 群组带来的记录不出现在“免打扰的用户”“忽略的用户”列表里，列表只显示自己单独设置的人；保存页面时插件会保留这些记录。
- 在用户卡片上把群组里的某个人单独改回“正常”，这个人会一直保持正常，直到取消再重新选择这个群组。
- 把群组里的某个人加进“免打扰的用户”列表，他就算自己单独设置的了，以后取消群组也仍然免打扰。

关闭 `mute_enhancements_group_mutes` 后，已经生成的记录保留，只是不再随成员变化更新，个人设置里也不再显示这两项。
