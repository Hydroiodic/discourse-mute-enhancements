# 对群组成员隐藏个人设置页面

群组 → 管理 → [成员偏好](member-preferences.md) 页面的“对成员隐藏的个人设置页面”有三个复选框，“通知”“跟踪”和“用户”，分别设置，默认都不勾选。勾选的页面，这个群组的成员在个人设置里看不到：顶部标签栏和侧边栏的用户导航里都不显示，直接打开它的链接会转到“账户”。

- “通知”页面是通知的方式（点赞通知频率、桌面推送、通知时间表等），以及插件加在这里的选项，例如 enhanced-ignore 的增强屏蔽；和[给群组成员打开增强屏蔽](group-enhanced-ignore.md)一起用时，成员就不能在界面上关掉这两个选项。“跟踪”页面是类别、标签的通知级别和话题跟踪设置；隐藏它时，单独的旧标签页（`/u/用户名/preferences/tags`）也一起隐藏。“用户”页面是免打扰、忽略的用户和群组。
- 成员在多个群组里时，隐藏的是这些群组勾选的页面的并集。
- 改动立即保存，并记一条管理日志。成员刷新页面后生效。
- 管理员和版主即使在群组里也不受影响，避免管理人员把自己锁在外面。
- 只是隐藏页面：页面上已有的设置照常生效，服务端也照常接受修改，成员仍能在别处修改，例如在用户卡片上忽略或免打扰别人、在类别和标签页面改通知级别。
- 隐藏的页面存在群组的自定义字段 `mute_enhancements_hide_preferences` 里，逗号分隔（`DiscourseMuteEnhancements::HiddenPreferences`）。
